## Current implementation

- `tbm_replanning.h` publishes transient `TBMExtensionPreview` and `PreviewTBMExtension`. The implementation is in `tbm_project.cpp`, so actual private reference/admission queries and the final controller revision remain with that owner.
- The extension preview requires an owned paused unfinished project, live references/model/origin, the actual measured independent wagon capacities and usable paid retreat support. It calls the verified geological continuation planner/append estimate, checks the physical rail-turn rule and returns only additional work. Its fingerprint binds geometry, quantities and stable participants; it deliberately excludes idle/phase timers and the changing controller revision while paused.
- `CmdExtendTBMProject` revalidates the full quote, expected geological revision and fingerprint, then commits geology before incrementing the existing controller revision. It allocates no machine/project/job and charges no second capital invoice; actual future cuts retain their existing work/running charges.
- `MakeTBMWorkOutline` in `tbm_area.cpp` is the shared bounded rectangle/one-cell-ring builder for fresh commissioning and extension. Fresh commissioning still uses `AuthorizeExcavationOutline` and its existing material/admission checks.
- `TBMCommissionAreaPreview` now carries a fingerprint. `CmdConfirmTBMCommission` binds the reviewed new/reused-machine decision, geometry, quantities and price; `CmdCommissionTBM` remains the immediate original entry. The area palette now uses the confirmation command. A removed reuse candidate must not silently turn its old quote into a new purchase.
- The actual Projects browser has Pause and extend / Extend work. It uses the existing pause command and opens the same explicit-layer palette at the accepted route endpoint. The palette holds a distinct existing project ID and extension quote, shows the actual machine/additional cost, and confirms through the new command. Successful submission opens the real portal controls for Resume. Cancellation clears presentation only; the actual pause remains deliberate.
- Existing new-project quotes explicitly label eligible retired-machine reuse. No alternate hangar, completed-job reopening, corridor intent or new route overlay is implemented in this slice; those remain later tasks.
