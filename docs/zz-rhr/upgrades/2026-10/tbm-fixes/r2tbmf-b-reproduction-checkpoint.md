## Confirmed diagnoses

- **Placement never arms after a real click.** `DispatchLeftClickEvent` lowers a `WWT_PUSHIMGTEXTBTN` before invoking its handler. `HandlePlacePushButton` treats that already-lowered state as a toggle-off and calls `ResetObjectToPlace`. Survey, Projects and Area use this incompatible combination. Real input leaves `_thd.GetCallbackWnd()` unequal to the palette; the area label nevertheless changes to the portal instruction. Subsequent map clicks perform ordinary tile actions. Earlier control-art tests called `OnClick` directly and bypassed the defect. Correct the widget/placement ownership first when resuming Groups2-3, and retain native input assertions.
- **Projects is also mislabeled.** Its handler expects a portal click; it does not create a project list. Correcting the momentary button alone will not satisfy the requested list/inspector.
- **Window size/empty rows reproduced.** The palette is786x569 at the measured scale, with three identical empty-area rows and no selected-project line. [Initial palette](../../../../../mlm/reviews/tbm/planning/import-20261009/images/tbm-feedback-palette.png) and [failed Projects click](../../../../../mlm/reviews/tbm/planning/import-20261009/images/tbm-feedback-projects-click.png) retain the actual layout.
- **Undefined status-bar text comes from the demo's company.** Company0 has `name_1=0`, `name_2=0`, and an empty custom name. `GetString(STR_STATUSBAR_COMPANY_NAME, company0)` produces the same undefined string. This is a saved fixture-name problem, not evidence of a missing TBM translation. Repair the playable copy via an actual naming command; preserve historical original input and investigate whether other fixture constructors need proper names.
- **The route already includes repeated geometry.** Twenty accepted segments begin `(13,75),(13,76),(14,77),(15,77)` in stacked coordinates, turn around and revisit earlier positions before finishing at `(15,83)`. Seven later cuts produce no spoil because their swept cells are already open. The normal run reaches cursor20 and four exchanges. Repetition alone is therefore not proof of random native routing. - **Hardness is uniform by layer.** All3,844 sampled playable inner cells are Soft Underground; all3,844 are Hard Deep. The current renderer selects layer/state/edge/texture without hardness. No geology was changed by this observation.
- **False order advice is real.** Native news history contains28 “too few orders” entries after20,000 frames. The existing formatter loses the vehicle label after shutdown, so identify each retained reference during runtime before claiming exact per-vehicle counts. `CheckOrders` still ignores controller ownership.
