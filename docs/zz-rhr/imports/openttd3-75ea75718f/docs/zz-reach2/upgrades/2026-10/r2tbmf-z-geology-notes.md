## Current implementation

- New maps select rock-region version1 with an independent U64 seed derived from the existing geology root. The frozen ore/vent generator remains version1 with identical stream consumption. Nine jittered Voronoi centres per query, on24-tile spacing, yield expected Underground60/25/14/1 and Deep5/15/60/20 percent Soft/Mixed/Hard/Basalt. Saved deposits override host rock. Surface RNG is untouched.
- Save399 adds ten bytes to the GEOS header (wire2). Existing398-and-earlier maps load region version0/seed0, preserving actual saved deposits and prior Soft/Hard layer defaults. Current resaves preserve that policy. Unknown algorithms, hidden legacy seeds and inactive regional state refuse. Legacy digests retain their original stream.
- Whole-unit yields remain Soft3/6, Mixed2/12, Hard1/20, Basalt1/24. Work rates remain Standard1/2 and Deep3/4. No fractional cargo representation exists.
- Base art reads the canonical hardness used by cuts. Transparent exposed-wall overlays read each adjacent uncut tile's hardness. Survey includes that same hardness. Previous terrain ranges remain packed at their original IDs; new material families append at2404 and2420, bound2436.
- Genuine built-in image generation produced [material bases](../../../../../../../../../OpenTTD3/docs/zz-reach2/upgrades/2026-10/assets/mlvs/raw/terrain-hardness-v1.png) and [material walls](../../../../../../../../../OpenTTD3/docs/zz-reach2/upgrades/2026-10/assets/mlvs/raw/terrain-hardness-edges-v1.png). Exact prompts, reference path and immutable hashes are in [generation record](../../../../../../../../../OpenTTD3/docs/zz-reach2/upgrades/2026-10/assets/mlvs/hardness-generation-record.json). Existing deterministic conversion crops/resamples/quantizes and removes declared magenta calibration floors for transparent walls; it does not synthesize artwork.
