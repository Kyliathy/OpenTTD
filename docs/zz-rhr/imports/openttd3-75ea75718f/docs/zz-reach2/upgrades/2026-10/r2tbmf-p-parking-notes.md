## Current authoritative behavior

- `TBMProject` has phase and interruption state; geology owns the sole cursor, accepted geometry and partial work. Pause preserves phase. Cancel currently releases unfinished geological claims immediately, then returns and exchanges actual spoil. Retire requires Completed/Cancelled, exchange idle, and a whole stopped empty consist on its original source tile or genuine depot. It removes the controller and unbinds the portal; the actual native train survives.
- `GetTBMCutterSteeringTarget` in `tbm_support.cpp` derives ReturnForExchange from `GetTBMExchangeBay`; forward targets use already paid accepted support. `AdvanceTBMWork` invokes actual `BackUpTBMConsist` on return. Work/cargo code must not perform a cut while parking is requested.
- `IsTBMExchangeDue` currently requires cancellation or a frozen pass breakpoint before checking actual spoil. Resumable early parking must exchange an incomplete pass's existing whole packets too; it must not discard them or require another cut.
- Hauler exchange observes `project.phase == WaitForEmpties`; update the parking wait equivalently while retaining actual identity/cargo ownership and empty capacity checks. A parked job keeps its work/support claims, so it is not the final release operation.
- `GetLayerPortalMagazineExit` recognizes the original commissioning key; cutter uses shaft, hauler outer door, service has an existing full-chain recovery rule. `IsLayerPortalMagazineBusy` already ignores another train's parts in `Track::Depot` while protecting moving parts on the housing. This is existing native storage, not a new invisible cargo/vehicle buffer.
- `ChangeLayerPortalConnection` currently uses `EnsureNoVehicleOnGround` for both ends and doors, so even a stored retired machine prevents public connection. Group7B must distinguish proven whole stopped stored trains from moving/partly stored occupancy, retaining demolition protection. `DescribeTBMPair` currently recommends SellMachine first; that must change for the requested reuse/public-through workflow.
- `WithdrawLayerPortalWorkPair` requires finished/cancelled geology and an empty rock-side endpoint/door; it already permits the withdrawn native Surface consist. `IsTBMSupportInUse` and corridor occupancy still own safe conversion. Do not blanket-clear claims or use a fake DepotID.
