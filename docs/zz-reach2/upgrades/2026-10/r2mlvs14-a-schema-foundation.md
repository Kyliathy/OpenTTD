# R2MLVS14 M0 execution record - schema foundation

Owner: [r2mlvs14-savegame-determinism-and-lifecycle.md](r2mlvs14-savegame-determinism-and-lifecycle.md), Groups 1-6. Consumer: [r2mlvs1 Content Freeze](r2mlvs1-gameplay-contracts-and-content.md#public-handoff-contract). Architecture: [archi-map-layers.md](../../architecture/map-layers/archi-map-layers.md). This foundation persists/validates metadata and publishes extension rules; later feature pools, mid-action serialization and multiplayer acceptance remain their owners' work.

Existing StationID, IndustryID, VehicleID, CargoPacketID and CompanyID keep their actual declared widths/invalid sentinels. Utility IDs and SolarMirrorID use their public producer declarations, invalid all-ones; no substitute private pool is introduced. Future Deposit/Job/Hub/etc types are **producer obligations**, not delivered records: each owner must publish its typed invalid value/cap and read-only validation/removal hooks before writing concrete data. World tiles use Map/MultiLayerMap bounds and explicit layer; fixed-point motion uses the Space owner's eventual type, never floating point or camera state.

Stocks use declared units/forms and bounded capacities; arithmetic widens before a whole atomic commit. A nullable target is distinct from a required missing reference. Missing/duplicate material custody refuses; it cannot be repaired by inventing cargo or reserves. Reservations are saved authority for active transactions, while route/spatial/network display indexes are rebuilt. Estimate/wire validation may inspect these fields but cannot consume inventory, energy, money, timer or RNG. Ownership/removal resolves every authoritative reference before dependent work resumes; a cache's stale reference is simply rebuilt.

## Group 2 - identity reservation and metadata scope

Inspected current enum ends at `DeepUnderground=370`; `MaxVersion` determines the writer's version. Reserve next symbolic **MultiLayerMetadata=371**, preserving 369/370 and vehicle enums. Registered chunk IDs contain no `MLMD`; allocate **MLMD** as one bounded table row, independent of feature chunks. Save/load/preview/fixup each validate that row; 371 requires it, older absence migrates to Classic. Native exact package validation must run after actual GRF definitions are loaded and before vehicle/industry gameplay resumes.

Metadata shape: schema version 1, explicit profile ID/version and policy flags, required GRFID/MD5/package version, feature flags, two 64-bit feature seed roots. Profile/version is the compatibility owner for 1980/model/factory dates and numerical recipes. Current M0 supports **no runtime feature bits**; unknown/nonzero feature payload claims refuse until an owning implementation registers its schema. Seed roots start zero without drawing the Surface RNG; later generators initialize them explicitly. Profile snapshots used by serialization/preview are transport views, not another live selected-profile authority.

The actual metadata fixture passed native new/save/reload/reload and three supplied older loads (Surface version 365, three-layer 369, Deep 370), with the pending new-game selector deliberately set to Multilayer during old loads. Each older input SHA256 was preserved. Important lifecycle discovery: `SlFixPointers` calls every registered handler, even for absent old chunks; MLMD fixup therefore permits absence, while new-version mandatory presence is enforced before activation. No older infrastructure is regenerated or buried. Evidence: [dedicated results](r2mlvs14-b-metadata-results.txt), [focused harness](../../../../src/tests/multilayer_state_fixture.py).

Load/preview parse exactly ten fields and one fixed wire row. Unknown policy bits are rejected before bool conversion; duplicates/extra/missing rows/fields, unknown schema/profile/features and mismatched identity refuse. Preview stores only independent preview metadata and checks exact resolved package identity without reading live cargo slots or publishing current policy. After actual GRF activation, the existing exact cargo-label validator runs before engine/industry gameplay resumes. The scaffold and actual saved profile therefore share the one content policy owner, with legacy absence remaining Classic. Feature payloads and live GUI preview-label review are still outside this foundation.

## Group 3 - legacy policy and conversion boundary

Surface-only and 369/370 saves keep their existing content, free underground building/working portals and saved numeric identities. Missing planes follow existing AfterLoad migration; no geology/native economy is generated on load. New explicit Multilayer saves carry the profile/version and policy instead of inferring it from a local selector. Restart follows the accepted policy. Existing-world conversion remains out of scope: a setting change cannot reconstruct excavation, replace cargo or turn buried infrastructure into a new-profile world. Any future conversion requires its own source/reserve/transport reconstruction and compatibility design.

## Groups 4-6 - wire, digest, diagnostics and public handoff

Concrete feature commands retain existing Command traits/estimate-before-execution boundaries. Their producer declares exact enum domains, actual typed ID width/sentinel, explicit layer/world coordinates and fixed-point/timer units. Decode rejects unknown enum/operation, out-of-map layer/coordinate, missing required target, unsupported profile/date and quantities above the producer's cap **before mutation**. Optional absent references use the type's declared sentinel. Validation cannot draw RNG, advance progress, reserve/debit material or charge money. M0 adds no undeveloped feature command or new vehicle category.

`ComputeMultiLayerStateDigest` is a portable diagnostic FNV-1a over explicit metadata, then actual owner-provided views sorted by feature kind/stable ID, then fields sorted by tag. Each unsigned/two's-complement bit field declares 1/2/4/8-byte width; overflow, duplicate record/tag or unknown kind refuses. Limits are 65,536 views and 128 fields/view. Kind, ID, count, tag and width delimit absent/empty records unambiguously. Profile/schema/content identity, policy and feature roots are included; later owners include reserve, packet custody/count, job phase/progress, RNG state, fixed positions, lease/grant intervals and remainders. No pointers, padding, unordered traversal, sprite frames, zoom, camera or rebuilt cache enters this encoding. This is a diagnostic extension point, not a second state pool or a whole-world desync audit.

`[multilayer-state-digest]` passed **12 assertions in one case**: independently encoded 55-byte Classic metadata hashes to `8f99d566ee8e00d7`; seed/policy/quantity changes alter it, record/field reordering preserves it, duplicates/overflow refuse, absent and empty differ, presentation changes are ignored. `LogMultiLayerStateDiagnostics` adds schema/profile/version, legacy/editor flags, seed roots and digest to the existing Desync facility after accepted load. Model/factory dates and 1980 Deep behavior are compatibility-versioned content, derived from saved policy plus the simulation calendar; ordinary new-game activation creates editor=false, while an explicit saved editor flag is restored only after content validation.

[Public schema](../../../../src/multilayer_state.h) exports `MultiLayerStateSchema` and `ValidateMultiLayerStateReferences`, plus staging/capture/digest hooks, in the existing CMake build. Structural/reference/staging and exact package preview checks passed **32 assertions in three cases**; the relevant original identity check also passed 17 assertions after sharing its package validator. Six dedicated metadata/legacy cases passed; supplied saves remain untouched. Foundation is ready for Plan 1 Content Freeze. Future concrete record descriptors, mid-action round trips, deletion/removal hooks, network joins/retries and complete desync comparisons remain Plan 14/feature tasks, all unchecked.
