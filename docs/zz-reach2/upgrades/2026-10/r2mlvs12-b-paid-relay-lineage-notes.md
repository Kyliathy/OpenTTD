## Working8C.1 contract proposal

The following is a proposed implementation shape to verify against all existing allocation/expiry/native owners before coding; it is not delivered acceptance.

- Keep one shared reservation owner. Introduce a bounded shared slice identity (`UtilityShareID`, not a producer or energy account), exact parent-slice reference, and ordered incoming physical segment on each electrical child share. Original generation stays at the existing producer, with epoch and actual published duration. The full original path reconstructs through retained parents; no feature-local registry, copied quantity or unbounded cache is allowed.
- Source roots have no parent/segment/imported link. A child retains the same original producer, names an existing earlier parent slice and stores only newly traversed local-cell/paid-edge IDs. Last native edge must agree with existing `imported_link`. A genuine older generic transfer keeps a one-edge segment and original root parent; generic imported re-export remains refused. Paid paths must never default through a generic fallback.
- Allocate slice IDs deterministically in the existing shared state, across both typed domains, without a separate pool. A proposed per-epoch counter resets only when the entire epoch's slices clear; other-domain allocation cannot reset or reuse it. Every positive root/child has one unique retained ID. Monotonic parent-before-child references give a bounded acyclic graph. Whole/current count and per-consumer limits remain enforced. Validate whether any existing operation deletes/reorders shares before fixing the exact native identity scheme.
- For every parent, `transferred_j` equals the sum of its direct children's original `allocated_j`. Original source reservation equals the sum of all free slices across the graph; source consumption is the sum of all settled use. Transferred parent quantities and their children are never both counted as free. Released/imported quantities are never generation. Each physical edge's flow sums child allocations whose newly traversed segment includes that edge; descendants must not recount their ancestors' segments. Local electrical-cell usage is derived from the same direct segments, while local cells retain zero stored flow/energy.
- A whole multi-hop transaction may bypass intermediate reservation demand: only the final destination receives usable availability. Every actual paid edge's registered endpoints remain topology references, and every arriving housing-to-next-inlet cable must exist. Creating artificial intermediate grants would require invented demand and duplicate quantities. A later explicit re-export from an actual imported destination creates a true child of that original slice. Parent identity is necessary to distinguish direct whole-path arrival from a staged arrival with the same producer/final edge.
- Physical capacity must use the original producer's actual published synchronized duration, never the caller's quote. For a shared cell/edge, contributions must agree on that duration; refuse ambiguous mixed windows before any write. Revalidate this against current driver/legacy interval behavior before freezing the policy. No per-source independent copy of one edge's200-kW budget is allowed.
- Whole preparation checks actual owned/date-valid original machinery/incarnations, installed ordered cable, no repeated account/edge/cell circulation, parent free quantities, target demand and shared residuals. Acquire all storage before committing; commit one operation sequence for the whole route. Serial calls that can partly export are invalid. Failed/forged/stale/repeated proposals leave every endpoint unchanged.
- On any traversed link/cell/source/company loss, expire each affected descendant's remaining free quantity once through the original source. Keep consumed/released/parent transfer history and spent physical flow. No donor refund or repair revival. Interval rotation clears its old graph and physical flow together, retaining original lifetime consumption/generation.
