# Joined lifecycle peers and replay

Owner: [Space fixes plan](r2sff1-space-fixes-features-1.md), Group32.
Architecture: [desync invariants](../../architecture/desync/archi-desync.md#invariants).

The native case `Native lifecycle converges across an owning client late join and local replay`
extends the socket/startup/checkpoint pattern in `probe_replay_native.cpp`.
`space_lifecycle_peer_checks.py` runs real loopback processes with isolated
assets/configuration under `test-cache/space-fixes/<run>/<mode>/`; native logs
and complete source/configuration/executable receipts belong in
`logs/space-fixes/`. Children retain the existing110-second process deadline
and native observers have a95-second bound.

The host starts from the earlier actual paid heavy miner's before-departure
save. Its last-safe attachment geometry is inherited and explicitly declared by
that predecessor. The host grants no hull, money, packet, reserve, permit or
elapsed time. Native CompanyAllowListControl allows access to this private
cloned company, and a native policy command establishes LegacyReturn while
paused. The host saves that actual `peer-input.sav`.

The owning client joins over the native socket and posts the checked Full Load
policy edit. The host unpauses only after observing the actual wire command's
result. Ordinary native opportunities then earn safety detachment, centre exit,
credit, the entire randomized interval and replacement. A second client joins
only after the host emits the actual credit checkpoint. The two GUI clients
select Space and Surface respectively and request different rendering rates.

Every completed opportunity records its actual field elapsed count, assigned
network frame and fifteen synchronized observations, including complete field
and native mission/cargo/endpoint owners, both global words and company money.
The field digest includes both complete private renewal streams. Named phases
also save/check full native transport. The late join's shared checkpoints start
at the fixed armed-timer watermark; it cannot claim to have witnessed the
earlier departure. Independent local and reversed-body-storage twins start from
the host's actual paused policy predecessor and execute the same checked edit
before their first ordinary opportunity.

Native source: `src/tests/space_lifecycle_peer_native.cpp`, registered in the
ordinary `openttd_test` target with hidden tag `[.space-lifecycle-peers]`.
Run with `space_lifecycle_peer_checks.py --source <actual predecessor> --run <unique-id>`
and `--configuration Debug` for that configuration. The default current peer
source has original low-ID cargo; high-ID origin acceptance is a separate
remaining part of32.3 and is not claimed by these runs.

Verification results and diagnostic run identities will be recorded after
successful socket execution. Initial compile diagnostics corrected explicit
native include boundaries and replaced guarded std integer parsing with the
project's checked `ParseInteger` helper. An initial demo-play configuration
did not complete GUI connection startup within the readiness budget; the
observer now uses the established minimal64x64 socket configuration. That
failed run is diagnostic evidence, not a successful join.

its private `process.json` before world observation. On a first failure, the
driver emits `<run>-failure.json` referencing those receipts and retains all
native traces/partial saves. A tuple mismatch identifies the exact elapsed
opportunity and all compared owners; frame equality is required only for actual
network peers. No global-RNG-only shortcut qualifies these comparisons.
